# Macaroons — сайт-каталог

Учебный frontend-проект: адаптивный сайт-каталог французских пирожных макарун. В проекте реализованы презентационный первый экран, блок с преимуществами, каталог со слайдером, форма заявки и мобильная навигация.

> **Статус:** учебный демонстрационный проект. Название, тексты, цены, телефон и сведения о кондитерской взяты из исходного макета и не являются подтверждением существующего бизнеса или реального предложения услуг.

## Демо

Ссылка появится после публикации проекта на Vercel или GitHub Pages.

## Стек

- HTML5
- CSS3 (в том числе адаптивная вёрстка и CSS-анимации)
- JavaScript
- jQuery
- Slick Slider
- WOW.js и Animate.css

## Возможности

- Адаптация интерфейса под мобильные устройства и планшеты.
- Мобильное меню с открытием, закрытием по крестику, выбору пункта и клавише Escape.
- Слайдер карточек товаров.
- Переход к каталогу и форме заказа.
- Подстановка выбранного товара в поле формы.
- Проверка заполнения полей и базовая проверка номера телефона.
- Отображение состояния загрузки и обработка успешного/неуспешного ответа сервера.

## Запуск локально

Сборщик и установка npm-зависимостей не требуются.

1. Скачайте репозиторий или клонируйте его:

   ```bash
   git clone https://github.com/Mit-10/macaroons.git
   ```

2. Откройте папку проекта.
3. Запустите `index.html` в браузере. Для удобной разработки можно использовать расширение Live Server в VS Code.

## Форма заявки

Форма отправляет тестовый POST-запрос на `https://testologia.ru/checkout`. Это учебный endpoint из исходного проекта; перед использованием сайта в реальном бизнесе его необходимо заменить на собственный backend/API и согласовать формат ответа. Успешная отправка зависит от доступности внешнего тестового сервиса.

## Публикация

Проект можно развернуть на Vercel как статический сайт:

- Framework Preset: **Other**
- Build Command: оставить пустым
- Output Directory: `.`
- Install Command: оставить пустым

После импорта репозитория достаточно запустить Deploy. Файл `index.html` находится в корне проекта.
